🤖 Autoencoder Training for Out-of-Sample Detection

📋 What This Does:

  1. Trains an autoencoder on 10,000 MNIST digits (50 epochs)
  2. Tests with 90° rotated images to establish outlier thresholds
  3. Creates dynamic quality thresholds based on actual performance
  4. Shows detailed visualizations in 3 tabs: Training, Evaluation, Out-of-sample
  5. Generates model files and statistics for production use

⚠️ Requirements:

  • Good internet connection (downloads ~11MB MNIST data on first run)
  • Keep this tab open during training (~10-15 minutes)
  • Open dev tools (F12) to see detailed console logs
  • Training uses 10,000 samples + 2,000 validation samples

📊 What You'll See:

  • Training Tab: Real-time loss curves and epoch progress
  • Evaluation Tab: Normal MNIST reconstruction quality
  • Out-of-sample Tab: Rotated images as outlier test
  • Console: Dynamic thresholds and detailed statistics
  • Downloads: Model files (.json + .weights.bin)

🧠 Model Architecture

The autoencoder uses the following architecture:

  • Input: 784 pixels (28×28 flattened)
  • Encoder: 784 → 128 → 64 → 32 (bottleneck)
  • Decoder: 32 → 64 → 128 → 784
  • Loss: Mean Squared Error (reconstruction error)

🎯 Out-of-Sample Detection Method

The system creates dynamic quality thresholds by:

  1. Training Phase: Learn to reconstruct normal MNIST digits
  2. Threshold Phase: Test with 90° rotated digits to find outlier range
  3. Dynamic Thresholds:
    • 🟢 Digit: Error < best rotated image (definitely digit-like)
    • 🟡 Unknown: Error between best rotated and worst normal
    • 🔴 No digit: Error > worst normal digit (definitely not digit)
  4. Production: Apply same thresholds to classify new inputs

💡 Why This Works:

Autoencoders reconstruct familiar patterns (digits) with low error, but struggle with unfamiliar patterns (non-digits), creating high reconstruction errors that can be used for out-of-sample detection.
