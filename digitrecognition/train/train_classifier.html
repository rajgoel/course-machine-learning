🧠 Train MNIST Digit Classifier

📋 What This Does:

This page trains neural networks to classify handwritten digits (0-9) using the MNIST dataset. You can train either a simple dense network or a more complex CNN.

⚠️ Before You Start:

  • Time: Training takes 5-15 minutes depending on the model
  • Internet: Will download ~11MB of MNIST data on first run
  • Browser: Keep this tab open during training
  • Monitoring: Open dev tools (F12) to see detailed progress

🏗️ Available Models

🔹 Simple Dense Network (Default)

Input: 28×28×1 → Dense(16) → Dense(16) → Dense(10) Activation: ReLU → ReLU → Linear Loss: Mean Squared Error Training Time: ~5 minutes

Use for: Quick training, educational purposes, simple digit recognition

🔹 Convolutional Neural Network (Optional)

Input: 28×28×1 → Conv2D(8,5×5) → MaxPool → Conv2D(16,5×5) → MaxPool → Flatten → Dense(10) Activation: ReLU → ReLU → Softmax Loss: Categorical Crossentropy Training Time: ~15 minutes

Use for: Better accuracy, learning about CNNs, production use

📊 What You'll See:

  • Input Data Examples: Sample MNIST digits
  • Model Architecture: Visual representation of the network
  • Training Progress: Loss and accuracy curves in real-time
  • Model Evaluation: Accuracy per digit and confusion matrix

💾 After Training:

  1. The model will automatically download to your Downloads folder
  2. Copy the .json and .bin files to ../models/
  3. Update ../digitrecognition.js to load your trained model
  4. Use in your slides for real-time digit recognition!

🔧 Customization

To modify the training:

  • Edit classifier.js to change model architecture
  • Uncomment/comment model lines to switch between simple and CNN models
  • Adjust epochs, batch size, and learning rate in the training function
🚀 Training will start automatically when the page loads
Check the TensorFlow.js Visor panel for live training progress
